### 🐞 BUG-007: Módulos npm F6 no declarados provocan 500 en compile (`inngest`, Redis, pdfkit)

> **Proyecto:** laborregamarket  
> **Fecha reportado:** 2026-08-17  
> **Reportado por:** Agente QA / Tester Senior

**Módulo / Componente:** Backend / Next compile  
**Severidad:** Major  
**Prioridad:** P1 - Inmediata  
**Caso de prueba relacionado:** suite F6 runtime  
**Estado:** Cerrado (17/08/2026 — compile F6 verificado: login/reports/rbac 200/401/403 reales; no se reobservó `Can't resolve 'inngest'`)

---

#### Descripción:

Al ejecutar Playwright contra `next dev -p 8080`, rutas API devuelven **500 HTML** porque Next no resuelve paquetes usados en código F6/F4. Evidencia en log del server: `Can't resolve 'inngest'` desde `src/lib/inngest/client.ts` importado por `order.service.ts`. Complementa BUG-005 (`@upstash/redis`) y BUG-006 (`pdfkit`).

Login a veces 200 y luego 500 al compilar rutas hermanas bajo workers paralelos (condición F5: no usar `next dev` en CI).

---

#### Pasos para Reproducir:

1. `npm run dev` en LaBorregaMarket sin instalar deps extra.
2. `npx playwright test tests/api/reports.spec.ts tests/api/rbac.spec.ts --workers=8`
3. Observar 500 y log `Module not found: Can't resolve 'inngest'`.

---

#### Resultado Obtenido:

51 failed / 2 passed (solo 401 anónimos que no disparan compile pesado). E2E: Chromium de Playwright no instalado en sandbox (`npx playwright install`).

---

#### Resultado Esperado:

Lockfile completo; 401/403/200 de contrato; CI con `next start`.

---

#### Evidencia / Logs:

```
⨯ ./src/lib/inngest/client.ts:1:1
Module not found: Can't resolve 'inngest'
Import trace: ./src/lib/services/order.service.ts → ./src/app/api/orders/route.ts
```

---

#### Workaround:

Instalar `inngest`, `@upstash/redis`, `pdfkit`; `npx playwright install`; correr API con `--workers=1` o `npm start`.

### 🐞 BUG-009: `GET /api/provider/reports.pdf` responde 500 (`Error interno`) con pdfkit instalado

> **Proyecto:** laborregamarket  
> **Fecha reportado:** 2026-08-17  
> **Reportado por:** Agente QA / Tester Senior

**Módulo / Componente:** Backend / `src/app/api/provider/reports.pdf` + `src/lib/reports/pdf.ts`  
**Severidad:** Major  
**Prioridad:** P1 - Inmediata  
**Caso de prueba relacionado:** `TC-REP-008`, `HP-DASH-06`  
**Estado:** Abierto

---

#### Descripción:

JSON de reportes (`GET /api/provider/reports`) cumple contrato (200, empty, KPIs). El PDF Must (`US-DASH-06`) falla: autenticado PROVIDER, `GET /api/provider/reports.pdf?grain=day&date=2020-01-01` → **500** `{"error":"Error interno"}`.

`pdfkit` **sí** está en `package.json` (`^0.19.1`) y genera `%PDF` fuera de Next. El fallo es runtime bajo Next (webpack no externaliza pdfkit; `next.config` no declara `serverExternalPackages`).

BUG-006 (deps ausentes) queda cerrado; este ticket cubre el 500 de producto.

---

#### Pasos para Reproducir:

1. App en `http://localhost:8080` con PROVIDER seed.
2. `POST /api/auth/login` `frutas@elparaiso.mx` / `Demo1234!`.
3. `GET /api/provider/reports?grain=day&date=2020-01-01` → 200 `empty: true`.
4. `GET /api/provider/reports.pdf?grain=day&date=2020-01-01` con la misma cookie.

---

#### Resultado Obtenido:

```
HTTP 500 application/json
{"error":"Error interno"}
```

UI: botón **Descargar PDF** visible y habilitado; el click dispara el GET y recibe 500.

---

#### Resultado Esperado:

200 `application/pdf`, `Content-Disposition: attachment; filename="reporte-*.pdf"`, magic bytes `%PDF`. Periodo vacío debe incluir copy “Sin ventas en este periodo.”

---

#### Evidencia / Logs:

- Playwright: `tests/api/reports.spec.ts` TC-REP-008; `tests/e2e/dashboard-reports.spec.ts` HP-DASH-06.
- Control: en `C:\Users\PC GAMER\LaBorregaMarket`, `node -e "require('pdfkit')..."` → `OK bytes 1338 %PDF`.
- `handleRouteError` enmascara el stack (`Error interno`).

---

#### Workaround (si aplica):

Ninguno para el Must PDF. JSON + Imprimir cubren consulta en pantalla.

### 🐞 BUG-017: Switcher y módulo Reportes generales no se montan con N=2

> **Proyecto:** laborregamarket  
> **Fecha reportado:** 2026-09-12  
> **Reportado por:** Agente QA / Tester Senior

**Módulo / Componente:** Frontend / UI panel PROVIDER (`useProviderScope`, `ProviderSwitcher`, `SubNavProveedor`)  
**Severidad:** Blocker  
**Prioridad:** P1 - Inmediata  
**Caso de prueba relacionado:** `TC-F11-101`  
**Estado:** Verificado
**US:** US-HEADER-01, US-DASH-11, US-AUTH-11

---

#### Descripción:

Con seed F11, `GET /api/provider/mine` en el **mismo** navegador tras login de `frutas@elparaiso.mx` responde 200 con `providerCount >= 2`. La UI del panel (`/proveedor`) no muestra el combobox «Frutería activa» ni el tab **Reportes generales**. El chrome queda como F10 (solo Catálogo / POS / Órdenes / Ventas). N=1 (Campo Verde) oculta esos controles de forma correcta (`TC-F11-102` Pass), pero el Must N>1 no se cumple.

Causa probable: `ProviderScopeProvider.reload` resuelve un `GET /api/auth/session` temprano (aún no autenticado) y deja `providers=[]` / `status=ready` **sin reintentar**. El evaluate posterior de `/api/provider/mine` ya ve N=2.

---

#### Pasos para Reproducir:

1. Aplicar migración `20260912160000_drop_provider_userid_unique` y `npm run db:seed`.
2. Abrir `http://127.0.0.1:8080/login`.
3. Entrar con `frutas@elparaiso.mx` / `Demo1234!`.
4. En `/proveedor`, inspeccionar header y `nav[aria-label="Panel proveedor"]`.
5. En DevTools: `fetch('/api/provider/mine',{credentials:'include'}).then(r=>r.json())`.

---

#### Resultado Obtenido:

- Mine: `providerCount >= 2` (Playwright `page.evaluate`).
- Combobox `aria-label="Frutería activa"`: **ausente**.
- Link «Reportes generales»: **ausente**.
- Evidencia: `tests/test-results/e2e-f11-multi-provider-E2E-de1bb-itcher-y-Reportes-generales-e2e-chromium/test-failed-1.png`

---

#### Resultado Esperado:

Según US-HEADER-01 y US-DASH-11: switcher visible si N>1 y módulo propio de reportes generales en la navegación.

---

#### Evidencia / Logs:

```json
{
  "request": { "method": "GET", "path": "/api/provider/mine", "credentials": "include" },
  "response_ok": { "status": 200, "data.providerCount": 2 },
  "ui": { "switcher": "not found", "globalNav": "not found" }
}
```

---

#### Workaround (si aplica):

Ninguno usable para el dueño N>1: no puede rotar sucursal ni abrir el módulo consolidado desde la UI. La API de switch y global **sí** funciona (TC-F11-002, TC-F11-005).

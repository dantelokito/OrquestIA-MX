### 🐞 BUG-010: Crash Blocker en `/explorar` — `FitCircle` llama `getBounds()` sin mapa Leaflet (`layerPointToLatLng`)

> **Proyecto:** laborregamarket  
> **Fecha reportado:** 2026-08-17  
> **Última actualización:** 2026-08-19 (escalado Blocker — repro al entrar)  
> **Reportado por:** Agente QA / Tester Senior

**Módulo / Componente:** Frontend / `ExploreMap.tsx` `FitCircle` + `ExplorePageClient` hydrate  
**Severidad:** Blocker  
**Prioridad:** P1 - Inmediata  
**Caso de prueba relacionado:** `HP-GEO-07`, `HP-GEO-08`, smoke `/explorar`  
**Estado:** Abierto

---

#### Descripción:

El módulo **Explorar queda inutilizable** por overlay de error de Next.js al cargar la ruta.

**Repro primario (F7 hydrate):** abrir `http://localhost:8080/explorar` (sin query). El hydrate de `ExplorePageClient` resuelve centro (URL, last-used, San Nicolás) y escribe `lat`/`lng`/`radiusKm`. Con pin presente, `FitCircle` ejecuta `useEffect` al montar el mapa → crash inmediato.

**Repro secundario (F6 slider):** en `/explorar?lat=25.6714&lng=-100.3089&radiusKm=10`, mover el slider `#radius-km` a 5 km dispara el mismo error vía `fitToken`.

En ambos casos:

1. Overlay Next: **Runtime TypeError** `Cannot read properties of undefined (reading 'layerPointToLatLng')`.
2. Stack: `FitCircle.useEffect` → `circle.getBounds()` en `src/components/explore/ExploreMap.tsx:122` → `ExploreMapSection` → `ExplorePageClient.tsx:86`.
3. El módulo no es usable; slider no hidrata URL ni dispara refetch (US-GEO-08).

**Causa raíz:** `L.circle([lat, lng], { radius }).getBounds()` requiere que el círculo esté añadido al mapa (`_map` definido). `FitCircle` crea el círculo **sin** `addTo(map)` y llama `getBounds()` → `_map` es `undefined` → `layerPointToLatLng` falla.

**Intento FE fallido (19/08):** sesión debug `98ad6d` / `runId: "post-fix"` solo añadió `dbgLog` e ingest a `127.0.0.1:7481` y `/api/debug/agent-log`. La línea 122 con `getBounds()` **no cambió**.

**Backend:** fuera de alcance. `GET /api/providers` responde 200; el crash es 100% cliente Leaflet.

- Código actual (`ExploreMap.tsx` 121–122):

```ts
const circle = L.circle([pin.lat, pin.lng], { radius: radiusKm * 1000 });
map.fitBounds(circle.getBounds(), { padding: [28, 28], animate: false });
```

---

#### Fix esperado (Frontend)

Reemplazar `L.circle(...).getBounds()` por `L.latLng(...).toBounds(metros)` y esperar mapa listo:

```ts
map.whenReady(() => {
  if (map.getSize().x === 0 || map.getSize().y === 0) map.invalidateSize();
  const bounds = L.latLng(pin.lat, pin.lng).toBounds(radiusKm * 1000);
  map.fitBounds(bounds, { padding: [28, 28], animate: false });
});
```

**Prohibido:** dejar `getBounds()` en círculo no añadido al mapa; conservar `dbgLog` / regiones `#region agent log` en producto.

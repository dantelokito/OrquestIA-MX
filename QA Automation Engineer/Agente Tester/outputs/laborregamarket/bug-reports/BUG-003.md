### 🐞 BUG-003: GET `/api/catalogs` sin query no usa envelope estándar ADR-003

> **Proyecto:** laborregamarket  
> **Fecha reportado:** 2026-08-05  
> **Reportado por:** Agente QA

**Módulo / Componente:** API / ADMIN  
**Severidad:** Minor  
**Prioridad:** P4 - Baja  
**Caso de prueba relacionado:** TC-ADM-012  
**Estado:** Abierto

---

#### Descripción:

Cuando `GET /api/catalogs` se invoca sin parámetro `catalog`, la respuesta retorna `{ catalogs: [...] }` en lugar del envelope estándar `{ data: { catalogs: [...] } }` definido en ADR-003.

#### Pasos para Reproducir:

1. Login como ADMIN.
2. GET `/api/catalogs` (sin query).

#### Resultado Obtenido:

```json
{ "catalogs": ["users", "providers", "products", ...] }
```

#### Resultado Esperado:

```json
{ "data": { "catalogs": ["users", "providers", ...] } }
```

- [ ] Unificar envelope en `src/app/api/catalogs/route.ts` default case
